Benvinguts al Curs

Aquest curs està dissenyat per aprendre a manipular el DOM HTML, estil·lar elements en temps real i gestionar atributs mitjançant JavaScript.

Modificar contingut HTML

Exemple per modificar el text d'un element utilitzant JavaScript:

document.getElementById("demo").innerHTML = "Nou contingut!";

Modificar atributs HTML

Exemple per canviar l'atribut src d'una imatge o un enllaç:

document.getElementById("miImatge").src = "imatge-nova.jpg";

Modificar estils CSS

Exemple per canviar el color de fons o estils d'un element amb JavaScript:

// Canvia el color del fons del document
document.body.style.backgroundColor = "#f0f0f0";
